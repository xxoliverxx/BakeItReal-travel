# BakeItReal · 画饼成真

> **Stop dreaming. Start slicing.**
> Turn "I want to travel" into a pie you actually eat, one honest slice at a time.
>
> A travel chat assistant (Trae hackathon project, theme: 画饼 / chat assistant / dreamy gradient) that turns "我想去云南放空三天" into 4 slices of a real dessert pie. Slices light up only when YOU finish the action — AI plans don't count.

把「我想去云南放空三天」这样模糊的念头，通过对话变成一条适合自己条件、可以开始执行的路线。助手「小饼」会逐步澄清目的/时间/出发地/预算（允许回答"不确定"），给出两条有取舍说明的路线方向，选中后切成**四块行动饼**——每块都有明确的点亮条件，**只有用户确认完成后才点亮**，AI 生成了计划不算进度。

## 如何运行

无需安装、无网络依赖：双击 `画饼成真.html` 直接在浏览器打开即可。
（也可以 `python3 -m http.server 8460` 后访问 `http://localhost:8460/画饼成真.html`）

## 90 秒演示脚本

1. **自动**：打开页面 → 点右上角「▶ 一键演示」，约 45 秒自动走完全流程：
   模糊想法 → 逐步澄清 → 两条路线卡片（含推荐理由与取舍）→ 四块行动饼 → 真实点亮第一块（饼块 squash & stretch 弹跳 + 1/4）→ 时间改成周末触发重校准 → 已完成且仍有效的块被保留（仍 1/4）。
2. **手动**（可选）：点「重新画一张饼」，输入任意旅行想法，用快捷回答或自由输入走一遍；试试输入「把预算改成5000元」看方案重排、已完成块保留；说「取消第一块」可以撤回点亮。

## 产品机制

- **诚实进度**：点亮只由用户确认触发（点击饼块/清单行，或聊天里说"完成了第N块"），可随时取消。
- **条件变化重校准**：改时间/预算/出发地时，助手明确说"原方案不再适用"，重新给两条路线；已完成且未受影响的行动自动保留。
- **不确定友好**：回答"不确定"时，"先定下来"会变成第一块行动饼（定窗口/定预算/定出发地）。
- **离线可演示**：纯前端规则引擎 + 预设演示路径，断网也能完整跑通。
- 进度与对话自动存入 localStorage，刷新自动恢复。

## 模拟范围（诚实声明）

- 路线与行动建议由本地规则引擎生成，**未接入任何大模型 API**。
- 「翻攻略」环节引用的博主经验来自**预置的示例灵感库**（按目的地分类、人工整理的通用心得），**非实时抓取网页**；后台对话中的口吻为演示设计。
- **不含**实时机票/酒店/地图/支付/预订数据；不提供真实价格、天气或签证信息（助手话术中已向用户声明）。
- 「一键演示」中的用户消息是预设脚本，其余交互均为真实输入驱动。
